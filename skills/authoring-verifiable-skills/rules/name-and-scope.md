# Name And Scope

Decision: **Where a name refuses to come, check the scope rather than the thesaurus, because the difficulty is the diagnosis.**

Use when:
- **A skill is being named or renamed.**
- **Several candidate names all read as contrived.**
- **A name collides with skills already installed**, and selection between them turns on wording.
- **A skill covers many decisions**, and no single outcome describes it.

Do:
- **Prefer verb, then the thing, then the quality it should have.** That names a judgement a reader can apply.
- **Use it only where the object is a concrete artifact with a truth value.** "The docs" is one. "The change", "the cause", and "the work" are not.
- **Take the shape each skill actually has.** Do not impose one pattern across a set.
- **Keep a category name that already carries what separates you from the neighbours.** Add the distinguishing word rather than replacing the name.
- **Treat a name that will not come as a scope report.** A skill covering ten decisions is either under-described by any one outcome, or has honestly risen to a category noun.
- **Record why a set carries two conventions**, so the next reader does not tidy it into one.

Avoid:
- **Naming an activity you cannot fail at.** "Maintaining written records" states no judgement, so nothing checks against it.
- **Forcing an outcome onto an abstract object.** Contrived names lose to plain ones.
- **Treating collision as a wording problem.** Being the fifth skill named around "review" is what loses activation, not failing to state an outcome.
- **Renaming to match a sibling's pattern.** Being distinguishable beats being consistent.

Exceptions:
- **A skill whose subject is one named ecosystem MAY carry that name.** A language skill naming its language is describing its scope, not coupling to a vendor.

Example (one instance, not the set):

| Name | Reads as | Why |
| --- | --- | --- |
| `make-the-docs-trustworthy` | a judgement you can apply | concrete object, and it has a truth value |
| `maintaining-written-records` | an activity you cannot fail at | no judgement, so nothing to check |
| `evidence-backed-review` | a category, plus what separates it | five installed rivals own "review" alone |

Verify:
- **Say the name aloud as an answer to "what does this do".** If the answer needs "and", the scope is two skills.
- **List the installed skills that would compete for the same request.** If the name does not separate from them, it has not done its job.
- **Check the name matches the directory**, since the checker treats a mismatch as a broken activation surface.
